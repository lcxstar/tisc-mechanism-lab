# Original author demonstration — final native topography figures

All 7 panels are generated from original author TISC .xyw output, without modifying geophysical inputs or running TISC again. These are **modern Matplotlib visualizations**, not the historical GMT -Pc output. The seven distinct model extents must not be treated as geographically co-located, nor should the model-specific min/max be used as a common scale.

Each figure has both PNG and vector PDF versions and a native-grid QC JSON. This is strictly the final landscape, not time-slice drainage, geological isopach or full history.
